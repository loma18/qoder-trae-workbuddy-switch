电脑端启动方式
桌面端执行 buddy-switch serve --host 0.0.0.0，并放开 Host 白名单：
Linux / macOS：BUDDY_SWITCH_ALLOWED_HOSTS=192.168.1.5:57890 buddy-switch serve --host 0.0.0.0
Windows PowerShell：$env:BUDDY_SWITCH_ALLOWED_HOSTS="192.168.1.5:57890"; buddy-switch serve --host 0.0.0.0
把 IP 换成电脑在局域网中的实际地址，手机与电脑需在同一 Wi-Fi。
