怎么独立登录
1. 「账号」页点 ＋ 添加账号，先选平台（WorkBuddy / Qoder / Trae），再选国内版或国际版。
2. WorkBuddy / Qoder 可手机独立扫码授权；Trae 上游绑定桌面客户端设备私钥与 127.0.0.1:17388 回环，请粘贴 JWT 导入（一次导入，之后长期独立用）。
3. 签到、领积分、查余额、刷新凭据全部由手机直连各平台官方接口完成。
同步到电脑是可选的：只在「同步」页手动点才发生。
凭据说明
access_token 几小时过期，用 refresh_token 换新即可；refresh 过期才需要重新扫码。 两处时间分开显示，0 / 未知 不等于已过期。凭据只存本机，日志不打印明文。
可选：同步到电脑
手机端完全独立，以下功能用不到可以整页忽略。需要把账号交给电脑端 workbuddy-console 时才填：两端连同一 Wi-Fi，电脑端开启「局域网同步」。 协议与 fewards 一致（/api/lansync/*，默认端口 57900）。
手机 → 电脑
把本机账号推给电脑端控制台，由电脑端合并规则落库（等于在电脑上建号）。
电脑 → 手机
只读拉取：本机失效的账号补凭据、本机没有的直接建号，仍有效的一律不动。
离线备份（不依赖电脑在线）
导出明文 JSON 自行保管，或粘贴回来批量导入。
